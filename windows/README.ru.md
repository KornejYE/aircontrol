# AirControl для Windows x64 — предварительная версия

**Статус:** на Windows прошли 65 изолированных тестов логики жестов и адаптера ввода, без отправки реальных нажатий. На проверяемом ноутбуке интерфейс и камера запустились, две руки отслеживаются примерно при 15 кадрах/с. Управление курсором и игрой ещё проверяется. Smart App Control может блокировать Qt/NumPy и останавливать установщик до создания ярлыка. Установщик не меняет настройки защиты Windows.

Smart App Control не поддерживает исключения для отдельных приложений. Подробности: [Microsoft](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions).

1. Распакуйте весь архив. Запустите `windows/Install.cmd`.
2. Установщик создаст отдельный Python/окружение в `%LOCALAPPDATA%\Programs\AirControl`, проверит подпись Python и контрольную сумму модели. Интернет нужен для первой установки; ключи нейросетей не нужны.
3. Откройте ярлык **AirControl** на рабочем столе. Включите управление, разрешите камеру в параметрах Windows для настольных приложений.
4. Для начала выберите «Мышь рукой · весь компьютер» и покажите указательный палец. Кулак отпускает управление; Esc останавливает до выключения и повторного включения.
5. В настройках доступны относительное/прямое наведение, поле камеры, количество экранов, назначения жестов, масштаб двумя руками, прокрутка и игровой джойстик.

Медиаклавиши и мышь используют обычный Win32 SendInput. Драйвер, виртуальный геймпад, права администратора и доступ к игровому процессу не требуются. Windows может блокировать ввод в приложения с более высокими правами. Совместимость конкретной игры и её античита требует отдельной проверки.

Для Chrome/Edge установите распакованное расширение из `BrowserGestures` и выберите вкладку/окно для управления. Это позволяет управлять выбранным окном браузера отдельно от активной игры. Ярлык не включает камеру автоматически.

Жесты и камера обрабатываются локально. Состояние: `%LOCALAPPDATA%\AirControl`; журнал запуска: `Logs\app.log`. Перед обновлением закройте AirControl. Настройки остаются при обновлении, прежние исходники копируются в `PreviousVersions`.
